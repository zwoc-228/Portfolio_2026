# Portfolio 2026 — Round 44

Start at [START_HERE.md](START_HERE.md).

This is a static Three.js portfolio with local runtime dependencies. It needs HTTP serving (do not double-click index.html as a file URL).

```sh
npm run dev
npm run check
```

Deploy the contents of `dist/`. No build step or npm install is required to run the delivered site with Node.js 18+.

See [ROUND44_PORTFOLIO_MATERIALS_AND_MODELS.md](ROUND44_PORTFOLIO_MATERIALS_AND_MODELS.md) for changes, portfolio palette provenance, validation and rebaking instructions.
