# Round 42 — physical UI reflection + model material pass

## Implemented

1. **Writing / Research material language**
   - Rebalanced notebook cloth, page block, loose paper and page-edge materials toward the same warm handmade-maquette language as the Architecture model.
   - Restored visible micro-texture in the notebook HOME state instead of flattening it to near-pure white.
   - Increased subtle paper layering, edge offsets and top-sheet bow while keeping the anti-moiré construction.

2. **Main header redesign**
   - Capped the expanded header width so it reads as a designed object rather than a full-width browser toolbar.
   - Reused the level 2/3/4 ceramic surface tokens, border, radius and shadow language.
   - Rebuilt the internal hierarchy: brand / coordinates / role selector / utility navigation; role selector now behaves like the card filter controls.

3. **Porcelain navigation orb**
   - Replaced the matte-clay response with glazed porcelain PBR parameters: lower roughness, clear-coat lobe, stronger white specular and environment response.
   - Increased sphere tessellation and enabled a real cast shadow.

4. **Physically coherent UI reflections**
   - Removed the visible dependency on the old analytical long-smear card reflection.
   - Added `ui-reflection-proxies.js`: DOM card bounds are converted into reflection-only 3D billboards with real perspective pose.
   - `floor-reflection.js` temporarily enables these meshes only in the mirror-camera pass, so the desk reflection is generated by actual reflected geometry and the same blur pipeline as the 3D models.
   - Category, project and detail cards all use this path.

## Verification

`npm run check` passes after updating the porcelain-material regression assertion.
